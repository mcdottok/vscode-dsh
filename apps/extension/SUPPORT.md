# Support

Report problems through [GitHub Issues](https://github.com/mcdottok/vscode-dsh/issues). Include the extension version, runtime version, operating system, reproduction steps and redacted diagnostics. See the [compatibility contract](https://github.com/mcdottok/vscode-dsh/blob/main/docs/dsh-contract.md) for supported runtimes and limitations.

Never include connection addresses, credentials, prompts or private workspace data. For a security issue, use private vulnerability reporting in that repository if enabled. Otherwise ask its maintainer for a private contact without posting exploit details publicly.

This fork is maintained independently of its upstream project.
