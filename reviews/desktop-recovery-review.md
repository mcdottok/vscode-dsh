# Desktop 自动恢复检查

目标：CN-05，Windows 同机 Desktop 连接；扩展开发版本 0.1.78。

## 实现范围

- 既有配对继续使用 connect 的 owner-only 注册、当前用户保护的 bootstrap 与认证加密 IPC；不增加上游 RPC。
- 连接中断后进入有限的自动恢复窗口，刷新授权和地址后重新验证服务。恢复成功同步 origin、版本及 SecretStorage 的配对绑定；瞬时失败只投影为连接中状态。
- 旧 loopback 配置丢失配对信息时，先验证原目标，失败后只接入唯一可信桌面端。已有配对则按原 key 约束发现，不按进程新旧猜测实例。
- 切换目标、清除凭据、重置、取消、撤销信任及释放扩展会停止旧任务。恢复写入受配置选择 revision 和队列保护，失败回滚。
- 远程目标、独立本机服务及明确端口列表保持原选择。恢复失败保留手动操作入口，桌面返回后仍可由观察器触发恢复。
